# Artifact Geeks · Campus Recruitment Training (CRT) Portal

The official, premium web platform developed by **Artifact Geeks** to guide students through a structured **90-Day Placement Preparation Program**. This portal serves as the primary reference guide for Artifact Geeks' training initiatives, supporting students, faculty, and Training & Placement Officers (TPOs).

## 🚀 Overview

The **CRT Project** is a modern documentation and learning platform built to bridge the gap between academic learning and industry requirements. It provides a step-by-step roadmap for students to develop aptitude, technical skills, and professional soft skills required to succeed in campus placements.

## ✨ Key Features

- **Modern Hero Experience**: A professional landing page with animated badges, icon-based statistics, and a "What's Inside" interactive grid.
- **13 Specialized Chapters**: Structured content covering everything from Program Overview and CBT Portals to CRT Policies and Student Consent Forms.
- **Premium UI/UX**: A sophisticated Navy and Gold design system featuring glassmorphism effects, smooth transitions, and elegant typography (Playfair Display & DM Sans).
- **Full Responsiveness**: Optimized for all device tiers (Mobile, Tablet, and Desktop) with a fluid sidebar navigation and mobile-first grid layouts.
- **Interactive Navigation**: Seamless single-page transitions using a sidebar-driven content system with touch-friendly feedback.
- **Branding Ready**: Integrated favicon support and custom branding areas for "Artifact Geeks" and partner institutions.

## 🛠️ Technology Stack

- **HTML5**: Semantic structure for improved SEO and accessibility.
- **CSS3**: Advanced Grid/Flexbox layouts, custom variables, and CSS-based animations.
- **JavaScript**: Lightweight logic for dynamic content switching and mobile menu toggling.
- **Google Fonts**: High-end typography integration.

## 📱 Mobile Optimization

The portal is specifically tuned for mobile devices with:
- **Zero-Margin Layouts**: Maximum screen utilization for text-heavy content.
- **Touch Feedback**: Enhanced `:active` states for all buttons and interactive cards.
- **Off-Canvas Sidebar**: A sleek, sliding mobile menu for effortless navigation.
